# NBUSAI 教师工作台（Vue 3 + Flask）

面向高校教师的科研 / 教学 / 学生指导一体化工作台。前端 **Vue 3**（免构建、离线可用），后端 **Flask + SQLite**，一套代码覆盖 **14 个业务页面 + 12 个内置工具**，薄荷绿主题与桌面版保持一致；内置 **LangChain / LangGraph 智能助手**（可查询登记工作台数据、基于个人知识库回答专业问题），并可将个人学术简历以**固定链接公开发布**（内容随工作台数据实时更新）。

系统内置**账号体系与双角色**：教师登录后使用完整工作台；管理员进入**管理中心**，可查看所有教师的简要信息与四类统计（科研成果 / 学术交流 / 教学情况 / 学生指导），对教师登记的科研成果执行**审核（通过 / 退回 / 撤回、单条与批量）**，并新建、编辑、重置密码、停用或删除教师账号。

### 1.1 账号与管理端

- **注册 / 登录**：登录页支持注册教师账号（可选「演示数据初始化」），会话为签名 Cookie，有效期 14 天；密码使用 PBKDF2-SHA256 哈希存储。
- **管理端**：管理员登录后进入「NBUSAI管理中心」，含三个视图：
  - **数据概览**：全校汇总统计卡（在册教师 / 在研与全部项目 / 文献 / 成果 / 教学学时 / 指导学生 / 待审成果 / 学术交流）+ 教师横向对比表（含待审列，点击行进入详情）；
  - **成果审核**：跨全部教师的成果审核队列，按「待审核 → 已退回 → 已通过」排序；支持状态标签页、教师筛选、关键词检索、单条通过 / 退回（必填意见）/ 撤回、勾选批量通过 / 批量退回，并可点开成果查看字段详情与完整审核轨迹；
  - **教师管理**：教师卡片列表（含待审徽标），支持新建账号、编辑资料、重置密码、停用 / 启用、删除；
  - **教师统计详情**：单位教师的科研成果、学术交流、教学情况、学生指导四类统计区块（渐变教师名片 + 4 项核心指标、区块锚点导航、指标卡、环形图 / 条形图 / 仪表环、审核概况与审核轨迹、项目与教学清单、需约谈学生列表）。
- **数据隔离**：每位教师一个独立 SQLite 租户库（`data/tenants/<uid>.db`），物理隔离、教师接口无需 owner 过滤；账号集中存于 `data/users.db`。

### 1.2 成果审核闭环

审核状态**直接写在成果文档上**（不新增中间表），教师提交与管理员审核共用同一份数据：

| 字段 | 含义 |
| --- | --- |
| `auditStatus` | 待审核 / 已通过 / 已退回 |
| `auditNote` | 最近一次审核意见 |
| `auditBy` / `auditAt` | 审核人与审核时间 |
| `auditLog` | 审核轨迹数组（登记 / 通过 / 退回 / 撤回 / 重新提交，最多保留 20 条） |

- **教师侧**：新登记成果自动进入「待审核」并写入一条「登记」轨迹；已出结论的成果一旦改动核心字段（标题 / 类型 / 级别 / 作者 / 日期 / 状态 / 业绩分 / 关联项目 / DOI / 备注），自动回到「待审核」并追加「重新提交」轨迹。成果卡片与列表会显示学院审核状态、退回意见或通过提示。
- **管理员侧**：审核队列跨教师汇总，退回必须填写审核意见（前后端双重校验，≤200 字），单次批量上限 200 条；审核后待审数与业绩分实时回填到概览、导航徽标与教师详情页。
- **存量数据回填**：v2 之前登记的成果没有审核字段，服务启动时由 `audit.ensure_fields()` 统一补齐 —— 已是「已发表 / 已录用 / 已授权 / 已登记 / 已交付 / 已获奖」的视为**已通过**，其余（撰写中 / 审稿中 / 申报中…）进入**待审核**队列。

### 1.3 课程开放与学生公开页

课程资料支持**真实文件上传下载**，并可将课程**开放给学生直接访问**（免登录）：

- **课程资料**：课程详情页「课程资料」标签页可多选上传文件（单次 ≤10 个、单个 ≤64 MB），自动记录体积、类型与上传人；每条资料可下载、可删除（服务器文件同步清理）。种子数据里只有登记信息的资料会标为「未上传文件」，不对学生展示。
- **学生访问控制**：课程文档内嵌三个字段 ——
  | 字段 | 含义 |
  | --- | --- |
  | `published` | 是否对学生开放（关闭时学生打开链接只见「暂未开放」） |
  | `openFrom` / `openUntil` | 可选开放时间窗口（按自然日，含首尾；到点自动生效 / 失效） |
  | `shareToken` | 16 位随机访问令牌，学生链接为 `/c/<token>`，与课程 id 解耦防枚举 |
- **学生公开页**：`/c/<token>` 免登录展示课程横幅、任课教师、简介、教学大纲、**教学日历**与可下载资料，侧栏含联系方式卡；不可见时按原因给出「已关闭 / 定时开放 / 已结束 / 链接无效」四种提示，且**不下发任何正文数据**；公开接口剥离 `published / shareToken / students` 等私有字段。
- **教学日历**：按周维护「周次 / 日期 / 教学内容 / 学时 / 形式 / 备注」，公开页以表格展示并**自动高亮本周**；支持从教学大纲**一键生成**（逐章对应教学周，自动推算每周日期），行内容在服务端统一清洗（白名单字段、空行丢弃、周次缺失自动补齐）。
- **联系方式**：QQ 群号（手填）与**群二维码**（图片上传，按内容嗅探类型，≤4 MB）随课程维护，学生公开页可直接**扫码或放大查看**；教师手机号自动取自工作台个人资料，学生可一键拨打。
- **课程助教**：每门课可登记多名助教（姓名 / 身份分工 / 电话 / 邮箱 / QQ / 值班备注），在「课程助教」标签页展示，并通过「助教与联系方式」弹窗增删改；学生公开页侧栏同步展示助教卡，电话与邮箱可一键拨打 / 发信。名单与日历共用同一套服务端清洗（白名单字段、空行丢弃、长度截断、单课 ≤10 人），未开放课程不下发任何助教信息。
- **教师侧入口**：详情页顶部「学生访问」状态条实时显示当前状态、可下载资料数与访问链接（复制 / 预览），「开放设置」弹窗内开关、日期范围、保存后状态**实时预演**；课程列表卡片右上角也有可见性徽标，列表统计含「学生可见」数。
- **安全边界**：公开资料下载与二维码读取均二次校验可见性（关闭课程后直链立即失效）；资料与二维码存储路径强制以 `<uid>/<cid>/` 开头并防 `..` 穿越，教师无法把路径指向他人目录越权下载；删除课程时资料目录一并清理。

### 1.4 界面配色（5 套主题）

整套界面（含登录页、教师工作台、管理中心）由 CSS 变量驱动，**一键切换 5 套配色**：

| 配色 | 说明 |
| --- | --- |
| 薄荷绿 | 默认配色，与桌面版一致 |
| 橙色 | 温暖醒目，活力感强 |
| 蓝色 | 理性专业，学术蓝调 |
| 橙蓝 | 橙为主色、蓝为辅助，撞色搭配 |

- **入口**：顶栏调色板按钮（教师端与管理端都有）→ 弹窗选择；设置面板「界面配色」分区；登录页卡片底部也可直接选（登录前即可预览）。
- **即时生效**：点击色块立即切换并给出提示，选择保存在浏览器 `localStorage`（键 `fwb-theme`），刷新与下次访问自动恢复；此前选择过已移除配色的用户会自动回落到薄荷绿。
- **实现**：`frontend/js/theme.js` 在首屏渲染前应用主题（切换 `<html data-theme>`，无闪烁）；所有颜色均走 CSS 变量，深色主题下文字、徽标、阴影、输入框已全部适配。

### 1.5 常用网站（独立页面）

「常用网站」是发展区的**独立页面**（工作首页只保留概览与快捷入口），集中维护一键直达的学术与教学站点：

- **分组分节展示**：默认按「学术资源 / 教学平台 / 科研工具 / 公共服务…」分组分节，每节标题带数量角标，像一份个人网站导航；页面顶部统计卡显示网站总数 / 分组数 / 当前展示数。
- **关键词搜索**：按名称、备注、域名模糊过滤，与分组筛选可叠加，一键清空。
- **小卡片 + 自动图标**：每张卡片展示站点图标、名称与备注（无备注时回退主机名），悬停显示备注与完整网址；图标由**服务端自动抓取**（先试 `/favicon.ico`，再解析页面 `<link rel="icon">`，含 data:URI 与中文域名），抓取结果缓存 30 天，失败 6 小时内不重试。
- **永不出现裂图**：站点抓不到图标时，服务端现场生成**首字母头像**（同站同色的 SVG 渐变块）返回，前端 `<img>` 始终有内容，控制台不会有资源报错；图标加载成功后渐显替换。
- **增删改 + 分组**：「管理网站」进入编辑模式 —— 每张卡片浮出编辑 / 删除按钮，末尾出现虚线「添加网站」卡片；「添加 / 编辑」弹窗支持名称、网址、分组与备注，**输入网址后自动探测站点标题回填名称**，并实时预览图标与给出抓取状态。
- **拖动排序**：编辑模式下拖动卡片即调整顺序，排序始终基于「全部」的完整顺序落库（筛选态下拖动也不会打乱其他分组），刷新后保持。
- **安全边界**：仅接受公网 http/https 站点（拒绝内网 / 环回 / 链路本地地址，防 SSRF 探测）；按 magic bytes 嗅探图片类型，不会把站点错误页缓存成图标；抓取并发有闸门，不会占满 WSGI 线程池。
- **存量兼容**：功能上线前就存在的教师库会在启动时补一份出厂清单（`meta` 标记位保证只补一次，教师清空后不会被复活）。

### 1.6 个人简历公开页（固定链接）

工作台里的数据可以一键变成一份**对外公开的学术简历**，访客凭固定链接免登录访问：

- **发布卡**：公开开关（关闭后访客只见「暂未公开」提示）、固定链接展示与复制、新窗口打开、**打印 / 导出 PDF**（公开页自动唤起打印，版式与访客一致）、更换链接（确认后旧链接立即失效）。
- **固定链接**：`/cv/<token>`，token 为 16 位随机串、与账号 id 解耦防枚举，生成后长期不变；跨教师查找令牌时不暴露教师 id。
- **内容实时同步，不存副本**：项目 / 成果 / 学生 / 教学从各自页面自动汇总，教育经历、社会服务、联系方式、研究方向、头像在简历页维护 —— 教师改完，访客刷新即见最新内容。
- **简历区块**：数据概览、个人简介、研究方向、教育经历（时间线）、项目经历（在研优先）、论文发表（按年分组编号）、专利软著、社会服务（按类型分组）、学生指导、教学经历、荣誉奖励，共 **11 个区块可单独开关**；未填内容自动整段隐藏。
- **隐私白名单**：公开数据只含展示字段 —— 业绩分、内部备注、关联项目、审核状态与轨迹、**学生邮箱**、日程 / 待办 / 工具等一律不下发；未公开时接口只返回 403 + 原因，不下发任何正文。
- **头像**：上传后按内容嗅探图片类型（≤4 MB），落盘 `data/avatars/<uid>/` 并自动清理旧文件；路径强制 `<uid>/` 前缀且限制在头像目录内，无法指向他人文件越权访问；未设置时展示姓名首字。
- **自适应与深色**：公开页带锚点导航（滚动高亮）、响应式（桌面 / 平板 / 手机无横向溢出）、跟随系统深色模式与打印样式（自动隐藏导航与按钮）。

### 1.7 智能助手（LangChain / LangGraph + 知识库）

工作区独立页面，底层为 **LangChain 1.x Agent + LangGraph ReAct 执行图**，通过 OpenAI 兼容协议接入大模型：

- **回答排版**：回答按 **Markdown 渲染**（表格 / 列表 / 加粗 / 代码块 / 引用，本地化 marked，离线可用），模型输出的原生 HTML 一律转义显示，杜绝注入；工具调用轨迹折叠在回答下方。
- **管理教师工作台**：智能体可自主调用 11 个工具 —— 查询日程 / 待办 / 项目 / 课程（含大纲与教学日历）/ 学生 / 文献 / 个人资料，**登记日程与待办**（相对时间自动换算为具体日期）；多会话管理，气泡下方折叠展示**工具调用轨迹**（调了什么工具、拿到了什么），过程透明可追溯。
- **知识库（RAG）**：上传 txt / md / pdf / docx（单文件 ≤10 MB），服务端中文分块后建立 **BM25 检索索引**（jieba 分词，本地运行零额外费用）；回答专业问题时先检索知识库、**以「依据：文档名」标注出处**，未命中则如实说明。每教师知识库独立隔离，支持检索试测（先看会命中什么再问）。
- **模型可配置**：设置页内置 DeepSeek / 通义千问 / Kimi / 本地 Ollama / 自定义（任意 OpenAI 兼容服务）五种预设，切换供应商自动填充地址与模型；API Key 只存租户库且**只回显掩码**；支持一键连通性测试；未配置 Key 时对话被拦截并引导到设置页。
- **多租户安全**：会话、消息、知识库、模型配置全部存各教师租户库；工具闭包持有当前登录教师的 Store，跨租户数据不可达。

**设计要点**

- **数据模型**：教研数据是「嵌套文档」（项目带阶段与成果、学生带里程碑与沟通记录），因此用单表 `documents(collection, id, seq, data JSON)` 承载 15 个集合，`seq` 单调递增使 `ORDER BY seq DESC` 等价于前端的「最新在前」，天然支持任意深度嵌套。
- **字段规格驱动 UI**：12 个工具的表单由后端 `tool_specs` 以纯 JSON 描述，前端 `fwb-field / fwb-form / fwb-tool-runner` 按类型渲染 —— **新增工具无需改动任何前端代码**。
- **大文件走文件流**：上传落在 `data/uploads/<token>/`，运行产物落 `data/tmp/<token>/`，前端拿到的是下载 URL，不把大文件塞进 JSON；2 天前的临时目录自动清理，下载路径做了 token 校验与穿越防护。
- **统一响应**：所有接口返回 `{"ok": true, "data": ...}` 或 `{"ok": false, "error": "..."}`，前端据此统一提示。

## 4. 数据与备份

- 数据全部存在服务端 **SQLite**：`data/users.db`（账号）+ `data/tenants/<uid>.db`（各教师工作台数据），单文件、免安装、便于备份。
- **导出备份**：右上角齿轮 → 数据管理 → 导出数据备份（JSON），可用于换机迁移。
- **导入恢复**：同一面板选择备份文件，二次确认后覆盖当前数据。
- **重置演示数据**：一键恢复初始演示内容（清空本地修改，不可撤销）。
- 迁移到新机器：拷贝整个 `data/` 目录即可（含账号与全部教师数据），或在新机器上用导出的 JSON 导入。
- **忘记密码**：管理员在「教师管理」中重置；管理员密码可用 Python 重新生成哈希后更新 `users.password_hash`，或删除 `data/users.db` 重启（会重建全部演示账号）。

## 6. HTTP 接口一览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/auth/register` | 注册教师账号（可选演示数据初始化），免登录 |

| GET | `/api/admin/overview` | 全校汇总 + 教师横向对比（管理员） |

| DELETE | `/api/admin/teachers/<id>` | 删除账号及其租户库（管理员） |

## 7. 常见问题

- **端口被占用**：`python run.py --port 8001` 换个端口即可。
- **局域网同事访问**：用 `--host 0.0.0.0 --prod` 启动，防火墙放行端口后访问 `http://<你的IP>:<端口>`。
- **彻底离线运行**：前端只有 `vendor/vue.global.prod.js` 一个外部资源且已本地化，断网也能正常使用（PDF 工具依赖本机 pypdf）。
- **数据文件变大**：`data/tmp/` 与 `data/uploads/` 里的过期目录会在每次启动时自动清理（保留 2 天）。
- **想清空重来（含账号）**：停止服务后删除 `data/users.db`、`data/secret.key` 与 `data/tenants/`，重启即重建全部演示账号。
- **想清空重来（仅当前教师数据）**：设置面板 → 重置为演示数据。
- **环境变量覆盖数据目录**：`FWB_DATA_DIR`（数据根目录）、`FWB_USERS_DB_PATH`（账号库路径）。

## 8. 二次开发指引

- **改主题色**：直接改 `frontend/css/style.css` 里 `:root` 的品牌主色变量（`--primary` 系列）；或参考文件末尾的 `[data-theme="…"]` 块新增一套配色，并在 `frontend/js/theme.js` 的 `THEMES` 里登记即可全站生效。
- **加一个页面**：在 `frontend/js/pages/` 新建组件并注册到 `FWB.pages`，再在 `js/app.js` 的 `NAV_GROUPS` 与 `js/util.js` 的 `PAGE_META / NAV_PARENT` 各加一行。
- **加一个集合**：`backend/config.py` 的 `COLLECTIONS` 加名字 → `backend/seed.py` 加种子 → 前端 `js/store.js` 的 `data` 加数组即可。
- **加一个工具**：在 `backend/tools.py` 写实现并注册到 `TOOL_IMPLS`，在 `backend/tool_specs.py` 写字段规格，再在 `backend/seed.py` 的 `TOOLS` 里加一条 `{name, category, desc, url}` —— 前端零改动。
